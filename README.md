# Customer Service Chatbot using Python

## Project Overview
This project implements a rule-based customer service chatbot using Python. It responds to common customer questions about orders, delivery, returns, refunds, payment methods, and business hours.

## Objectives
- Build a simple interactive chatbot.
- Apply basic Natural Language Processing (NLP) techniques.
- Recognize user queries using text preprocessing and pattern matching.
- Provide automated responses to frequently asked questions.

## Technologies Used
- Python
- Google Colab
- Regular Expressions
- Python Standard Library

## Features
- Greeting detection
- Order status assistance
- Delivery information
- Return and refund assistance
- Payment information
- Business hours inquiries
- Unknown-query fallback response

## How to Run
1. Open `customer_service_chatbot.ipynb` in Google Colab.
2. Run each code cell in order.
3. Test the chatbot using sample questions.
4. Type `exit` to end the conversation.

## Example Questions
- Hello
- Where is my order?
- How long is delivery?
- What is your refund policy?
- What are your business hours?

## Limitations
This is a demonstration chatbot that uses predefined patterns and responses. It does not access real customer orders or process refunds.

## Future Enhancements
- Add a graphical user interface.
- Use machine learning for intent classification.
- Connect to a customer support database.
